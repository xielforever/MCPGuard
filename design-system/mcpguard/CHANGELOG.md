## 后续版本约定

- Patch：不改变交互语义的文案/链接/说明修正。
- Minor：兼容的组件/页面模式补充或数值收敛，说明受影响页面。
- Major：改变主视觉、语义 token 含义或关键交互，需要明确迁移与用户范围决定。

文档版本不替代 API 契约版本；规范更新不赋予生产权限，也不自动改变部署状态。
