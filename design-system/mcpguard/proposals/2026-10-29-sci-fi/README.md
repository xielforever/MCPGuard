# MCPGuard 科幻审批：第二轮视觉草案

日期：2026-10-29。状态：**等待用户选择方向；未迁移业务页面**。

本轮响应用户要求：“这个审批UI我希望设计的有科幻风格，不要太古板”。保留首轮 A/B/C 方案，在独立目录中新增 D/E 两个方向。

用 Chrome 或 Edge 直接打开 [单文件离线预览](preview-offline.html)，可以切换方案、申请、详情标签和样例身份，体验审批/拒绝确认及动效开关。页面不依赖服务器、第三方字体、CDN、npm 或图片素材。

## 两种方向

| 方向 | 视觉表达 | 审批结构 | 适用取向 |
| --- | --- | --- | --- |
| D 星舰 · 审批舰桥 | 深空蓝、青色边缘光、轨道关系图、几何框架、细网格；正文保持高对比 | 请求舱、授权轨道与变更面板、决定舱三栏；审批边界独立展示 | 科幻感更鲜明，适合用作 MCPGuard 的主视觉方向 |
| E 光舱 · 轨道中枢 | 银白舱体、蓝色主操作、橙色轨道点、空间层次与切角工作面 | 横向请求卡片、完整审阅工作面、独立决定面板 | 未来感更轻盈，适合长期阅读和白天办公 |

建议优先看 D。该方向将审批组织成有因果关系的工作空间，主视觉和操作布局同时变化。E 提供一条明亮的科幻方向，供比较深色与浅色使用感受。

## 交互与业务语义

- 请求包含受控写申请、资源账号/只读权限申请、结果未知和已批准待恢复四个样例。
- 关系图展示申请人、审批阶段、目标资源。图形不表示网络实时连接、风险评分或数据库健康状态；没有虚构实时数据流。
- 变更区可以对照样例快照与申请内容，并切换到冻结参数、决定轨迹。快照不能代替执行前的版本校验。
- 批准只记录决定；受控写仍需原申请者显式恢复。账号权限批准后仍须完成开通、私有交付和激活。
- 切换为 Alice 的申请人样例视角后，仅显示其本人可见申请，不显示 Bob 的请求，不允许自行审批。
- 结果未知明确展示“请勿重复提交”，只提供核对记录，不提供重试或重新执行入口。
- 审批/拒绝使用独立确认框。支持 Escape 关闭并回到触发按钮；详情标签支持方向键、Home 和 End。
- 轨道旋转是装饰动效，可手动关闭，后台页面暂停；系统减少动画设置优先。没有闪屏、持续滚动数据或阻塞操作的动画。

## 本轮范围

这些是可以操作的高保真设计预览，全部使用固定样例。它们没有 MCP 或业务 API 连接，不读取令牌、凭据或数据库，不保存审批决定，不创建账号、不执行写入、不发送通知。

审批中的资源权限字段属于流程设计示意，不充当已实现的版本化契约。选定方向后，正式页面仍须接现有契约、对象鉴权和状态规则；视觉改版不能改变安全边界。

本轮未修改后端、实际控制台、Vue 历史原型、数据库迁移、已生成契约和首轮方案。设计索引只追加本轮入口，改前索引另存于 `.dev/ui-scifi-2026-10-29/design-system-README-before.md`，其余改前文件 SHA-256 基线在同目录 `baseline.json`。本轮失败调试记录独立保留，不覆盖上一轮验收。
