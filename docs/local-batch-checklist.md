本地检查：80 个 Go 测试（含 race、真实 PG/Redis/HTTP、MCP SDK），56 项独立 HTTP/stdio 检查，20 项服务/续期单元测试通过（另 5 项需显式改动本机权限的旧测试未启用），19 项隔离控制台交互检查通过。开发测试均不冒充当前聊天原生调用。详见 [配置与限制](controlled-local.md) 和 [证据](validation/local-controlled-batch-2026-10-23.json)。

用户选择本机直连，因此本地审批链接使用固定环回 HTTP 地址；这是本地配置对原设计 HTTPS 链接约束的明确例外，不启用域名或隧道。运行时输出采用独立本地 schema，原设计 schema 保留。
