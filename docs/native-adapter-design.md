# MCPGuard 原生服务适配设计

状态：设计建议，具体工具和操作范围待确定。日期：2026-10-22。

网关对 IDE 提供 MCP 工具，通过原生驱动直接访问 PostgreSQL、Redis 与 HTTP API。后端不实现 MCP，不参与 MCP 版本或能力协商。

## 1 资源与工具契约

资源目录描述受管服务：resource ID、kind、地址和连接配置、归属、可访问主体、凭据引用与版本。服务在企业服务器还是员工电脑，仅影响地址与执行身份，连通条件按已有环境处理。

工具目录由网关定义，至少包含 tool name、inputSchema、outputSchema、资源绑定或允许资源集、adapter kind、operation、语义与策略引用、超时和结果上限。工具定义变更须版本化。

| 适配器 | 只读路径示例 | 受控写路径示例 |
|---|---|---|
| PostgreSQL | 查看结构、参数化查询模板、经约束的查询 | 固定操作或参数化写模板 |
| Redis | GET、有限 MGET、有界 SCAN | 指定 key 的 SET、DEL 等已注册操作 |
| HTTP API | crm.get_customer 等具体业务 operation | inventory.reserve 等具体业务 operation |

以上为候选工具，不代表已实现或已批准生产开放。首版已确定受控目录，验证必要读取与至少一条他人审批后的受控写路径；任意SQL、任意Redis命令和任意URL不进入v0.1，未来需要时另行设计。

例如 crm.get_customer 可绑定 team-a.crm，固定 GET 与 /customers/{customerId}，IDE 只传 customerId；网关从注册表取地址与认证，完成权限检查后调用业务 API。

## 2 冻结操作计划

先完成身份、工具与资源准入，解析出不可变操作计划，再依据完整计划评估允许、阻止或需人类授权。计划至少包含 action ID、工具与版本、调用者、资源与版本、实际后端身份、完整业务参数、适配器操作、策略版本、前置条件、期限和限制；评估结论绑定该计划及策略版本。

PG 计划固定 SQL 模板版本及参数；Redis 固定命令及参数和 key 范围；HTTP 固定 operation、method、地址绑定、路径与查询参数及 body。审批展示与最终执行使用同一业务计划，不能批准后再次让模型生成命令。

驱动不接收模型自带连接串、密码或任意认证头。资源 ID、operation ID 与凭据引用均由服务端解析、验证归属和权限。

审批等待期间不持有事务、锁或专属连接。需要预览时只做无副作用查询，并注明预览时点与已知限制；变化影响审批语义时重新计划，不能把预估数量当作执行保证。

## 3 PostgreSQL 适配器

使用 PostgreSQL 原生驱动，连接池按资源、实际角色、凭据版本和连接配置隔离。数据库连接使用最小权限角色，不使用超级账号；查看不同 schema、表及函数的权限由数据库和网关共同约束。

只读工具优先采用审查过的查询模板，配合只读事务、执行超时、锁等待上限、结果行数与字节限制。参数值使用绑定参数；动态标识符必须从已授权元数据中选择或安全构造。

不能靠 SELECT 前缀或关键词正则证明只读。多语句、写 CTE、可调用函数、SECURITY DEFINER、外部访问及管理能力需要单独限制；参数化解决值注入，不证明操作已授权或无副作用。

普通查询入口不允许自行控制事务、切换角色或修改跨调用会话状态。READ ONLY 不是外部副作用沙箱，也不能替代对敏感数据、函数权限和资源消耗的限制。

写工具使用明确模板与权限。原生事务仅覆盖同一 PG 数据库事务内操作，不跨 Redis 或 HTTP。人类批准后才获取执行连接、检查前置条件并开启必要短事务。不能把 EXPLAIN ANALYZE 当成不执行写操作的预览。

需限制影响行数的操作，应在适配器拥有的事务中根据实际结果判断是否提交；预览或估计不能代替该检查。

取消使用驱动取消机制；确认语句结束并完成回滚或连接清理后才能归还池。事务和会话状态需隔离或清理，不能让角色、search_path 或未提交事务泄漏给下一调用。COMMIT 之后响应丢失时，不能直接认定回滚或自动重发。

结果保留列名、列类型与行数据，重复列名不能相互覆盖；大整数、Decimal、时间及二进制采用明确编码，返回截断说明与实际已读取范围。

## 4 Redis 适配器

使用 Redis 原生客户端与 RESP，配置最小权限 ACL 用户、允许命令和 key 范围。以参数数组构造命令，不把拼接字符串当安全边界。

读取采用受控 GET、MGET 和有界 SCAN。SCAN 的业务 cursor 与 MCP tools/list cursor 是不同概念；扫描需限制返回数量、工作量与输出大小，不能把逐页扫描视为稳定快照。避免将 KEYS 作为无界浏览工具。

不能假定 Redis key ACL 会自动过滤所有枚举结果。适配器按实际命令、子命令、选项和全部 key 检查授权，枚举工具额外限制可见范围；AUTH、SELECT 等连接状态由适配器管理。

写操作固定命令、参数、key 集合或明确的受限操作语义。删除等预览若在执行前已变化，按前置条件决定重新确认；不能在批准后无界扩张目标集合。

Lua、脚本、MULTI/EXEC、管理命令及模块命令另行分类，不默认从普通命令入口继承权限。Redis 原子执行不等于错误时可自动回滚，脚本或事务错误后的实际效果须按命令语义判断。

命令发出后取消等待不能撤销操作。连接存在未消费响应或协议状态不明时，不能直接归还连接池。写命令是否重试由具体幂等和状态证据决定。

二进制 key 或 value 使用明确编码。结果需表达不存在、空值、类型错误、过期信息及截断，而不是统一转换为无法区分的空字符串。

## 5 HTTP API 适配器

管理员注册 service 与 operation，固定目标地址、method、path 模板、输入输出 Schema、认证方式和策略。模型只提供该 operation 接受的业务参数。

URL、path、query、header 和 body 分别构造；动态参数不能替换目标主机、认证或越权路由。重定向和认证转发受限，不能因物理可达而允许任意地址或管理接口。

GET 不天然代表无副作用，POST 也不自动等于高风险；操作语义由已审核业务定义决定。OpenAPI 可辅助导入工具草稿，导入后仍需审核权限、身份和副作用。

使用超时、大小上限和明确解析规则。访问网关的员工 token 不透传为业务 API 认证；下游 HTTP 401、403、429 或 5xx 映射为工具执行状态，不冒充员工的 MCP OAuth 错误。

写接口只在后端明确支持并实际校验幂等键时，使用稳定 execution ID 等受控键进行恢复。断开 HTTP 请求不证明服务端没有提交；不能按网络库默认重试盲目重放写操作。

## 6 统一执行与结果语义

适配器接收计划、调用者与执行身份、execution ID、deadline、取消上下文和资源限制。它返回数据、适配器错误、已知执行证据与副作用状态，由 MCP 层组装工具结果。

区分验证失败未派发、已派发成功、已知失败及结果未知；同时记录副作用是否可确定。FAILED 或 isError 不自动表示完全未生效。只在有证据时声明未执行或回滚。

原生错误需脱敏，不能返回密码、连接串、内部认证头或无需暴露的地址。日志与审批页使用摘要或受控详情，摘要不能替代计划对完整参数的绑定。

## 7 隔离与验证

连接复用不代替员工鉴权。即使两人最终使用同一后端服务账号，也应分别校验资源与操作权限并独立记录审计。凭据轮换淘汰旧池；计划中的身份或配置变化触发重新检查。

单元测试可替换驱动以验证策略、计划和结果映射。集成测试使用真实测试 PG、Redis 与可控制响应的 HTTP 服务，覆盖认证、连接池状态、事务、二进制与数值编码、取消和断连。

完整链路从无模型 key 的 MCP 客户端进入真实网关，再访问原生服务，执行无害测试数据。授权另接模拟企业身份与 IM。未取得明确授权不接真实生产资源，不把旧模拟 MCP 后端作为原生协议验证。

需要验证的关键失败为：无权资源、操作替换、审批后数据变化、重复派发、PG 提交结果丢失、Redis 响应未读与部分副作用、HTTP 写入后超时，以及原生认证失败不触发错误的 MCP 登录流程。
