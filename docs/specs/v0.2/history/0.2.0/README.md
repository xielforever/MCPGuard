# 0.2.0 历史契约快照

这是 RA-01/02/03 完成时的机器契约候选，按 RA-04 开发前工作树归档的原始字节保留。来源和逐文件 SHA256 见 [manifest.json](manifest.json)。它不参与当前生成和运行；历史 Go DTO 使用 `.txt` 后缀，避免被编译为额外包。

该候选定义了未来申请和授权字段，当时只注册资源目录。RA-04 的当前契约修订为 0.2.1：待开通授权允许没有 accountId/bindingId，ACTIVE 仍要求二者；状态接口关联申请、决定和授权，加入显式审批策略和受保护控制台 API。当前规范源与生成物见 [v0.2 说明](../../README.md)。

历史候选中出现某个接口或状态不证明其当时已实现；历史验收的范围仍按原记录理解。
