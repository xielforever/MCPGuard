## 实现结果

| 项目 | 结果 |
|---|---|
| 申请 | 当前主体校验，不接受 owner/decider/nativeIdentity/SQL 选择器；限定显式资源、套餐及策略期限；冻结版本、资格与 HMAC 摘要 |
| 决定 | 独立浏览器认证和 CSRF/Origin/If-Match/幂等校验；按资源限定审批资格；禁止自批、跨资源、跨组织、旧摘要和旧 revision |
| 授权 | APPROVED、决定、PROVISIONING 授权及审计原子提交；不伪造账号/绑定，不创建原生账号，不允许直接 ACTIVE |
| 终态 | 拒绝、本人取消、待批过期、资格变更 STALE；待开通授权过期 EXPIRED 或资格失效 REVOKED；原批准事实保留，终态不恢复 |
| 幂等和并发 | 并发同键申请复用一份记录；同键异载荷冲突；并发决定唯一胜者；取消/批准竞争只能一方成功；移除审批权后旧键重放仍拒绝 |
| 隔离与状态 | 请求/授权按主体、组织隔离；审批队列按资源限定；游标绑定主体及筛选；目录反映最新流程和套餐期限 |
| 持久性与审计 | 申请理由、决定及幂等响应加密；关键审计失败使决定/授权一起回滚；运行角色不能管理策略或删除审计；实际进程重启后关联状态保留 |
| 增量迁移 | 新增独立目录迁移 002；旧目录 v1 的定义、可见性和申请资格原字节/值保留，升级到 v2 后重复迁移通过；原元数据 1..4 和目录 001 文件不改写 |
