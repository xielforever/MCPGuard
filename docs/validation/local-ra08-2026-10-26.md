## 2 实现与安全边界

初次准备在加密前提交不可回收 nonce 预留；最终事务原子提交引用包、租约、ticket、命令幂等及关键审计。准备结果只包含安全 ID、ticket 期限、包期限、revision、MANUAL_OWNER 模式和状态，没有密文字节、私有令牌或下载 URL。

每主体/授权使用服务器派生的稳定签发键。新 requestKey 产生新 ticket，复用原包和租约，不新增授权、不续活包、不调用原生账号提供方；原始调用者幂等键只保存 HMAC。相同 requestKey 返回原 ticket 的当前状态，不把消费过的 ticket 改回 READY；改 grant 会冲突。显式 ticket TTL 为 1..300 秒且不超过包期限，READY 配额为每主体 1..50，初查和提交时均校验。

私有状态和 claim 同时要求当前员工认证及独立 256 位 credential:claim 授权，audience 固定 mcpguard-delivery，并绑定组织、主体、凭据指纹与到期时间。原始私有令牌只通过受控私有文件登记，数据库只存 verifier HMAC；没有模型可调用的登记接口。Cookie、Origin、query、MCP session、ticket ID 或自报 clientInstanceId 都不能代替私有认证。

claim 在发送前原子提交 CLAIMED 和关键审计，之后才向私有 writer 交付密文。发送失败、取消或结果未知都不恢复 READY。独立最长两秒的结果审计只写固定码；WRITE_COMPLETED 指服务器 writer 接收完整响应，不能当成客户端已经收到、保存或激活。响应后审计失败为 UNKNOWN，不猜成功、不重放。

单次组件只需员工 token 和私有下载授权，不需要服务器密钥、元数据 DSN 或数据库密码。完整接收后校验固定包格式、长度、文件名和摘要，以 0600 临时文件同步后无覆盖地原子发布；拒绝不安全目录、符号链接、工作区目标、重定向及覆盖。不自动重试 claim，错误只输出固定安全文本，成功只输出安全保存回执。

公开新增 MCP credential.prepare_download 与 POST /api/v2/credential-packages；私有新增 GET ticket 状态及 POST claim。没有 MCP claim/decrypt 工具，没有批量同步/Context/激活接口，也未发布正式 pg.get_item。

## 4 实际网络中断和账号不变

实际进程对每套 PG 各验证以下场景：

| 场景 | 实测结果 |
|---|---|
| 8 个并发 HTTP claim | 1 个 200 文件响应、7 个 409；唯一响应与持久原包一致 |
| 代理在请求到服务端前断开 | 组件失败、目标目录为空、仅一次 POST；服务端状态 READY，核对后明确重试可领取 |
| 服务端已消费，代理截断响应 | 组件失败且无半文件；状态 CLAIMED，旧 ticket 再领 409；新 ticket 返回相同包 |
| 网关重启 | READY/CLAIMED 与私有授权继续持久有效，已消费 ticket 不复活；人工审批重新独立登录 |
| 撤权先提交 | 未领取 ticket 收敛为 CANCELLED，旧私有文件保留但服务端校验拒绝，新 ticket 不续活包 |

两套 PG 的真实原生账号总数，以及元数据账号/开通任务、授权版本、该 grant 的包和租约数量，在所有重领/网络中断/重启前后均一致；具体前后值在 JSON 的 download-e2e-results.json receipts 中。没有通过清空计数或重新播种来满足该检查。

## 5 数据库和审计事实

最终数据库快照有 **39 个 ticket**：原始行 READY 14、CLAIMED 21、EXPIRED 1、CANCELLED 3；有 **21 个 CLAIM_COMMITTED**、18 个 WRITE_COMPLETED、2 个 WRITE_INTERRUPTED，另 1 个 CLAIMED 无写结果，为明确注入的响应后审计失败，保持 UNKNOWN。重复 claim 事件为 0，数据库唯一索引禁止重复消费审计。

READY 原始行中 14 个已过数据库期限，属于保留的过期测试历史，不能将行状态当成当前可领取资格；在线读取/claim 会先按时间与当前资格收敛，过期行不占有效 READY 配额。原包/租约同样逐次检查当前授权。快照没有孤立租约、缺失 blob 的包、缺少原生证据的 ACTIVE 授权或运行中的读取探针。

审计表只有 seq、org_id、subject_id、download_id、credential_id、authorization_id、event_type、server_identity、created_at。没有请求/响应体、密文、原始令牌、URL 或任意错误文本；真实 MCP 返回、组件/服务器输出、应用日志和持久审计均对实际私有值做了不包含检查。审计中的角色是独立 mcpguard_credentials 和 mcpguard_downloads。

下载运行身份可读 blob，但没有原生秘密读取、开通任务 INSERT 或私有授权登记权限；普通网关身份不能读取 blob、私有授权和准备幂等表，也不能插入包。旧 grant 命令回归继续收紧新增私有表读取权限，未把网关提升为管理身份。
