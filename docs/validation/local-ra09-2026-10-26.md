## 2 三类失效和多资源结果

| 场景 | 实际结果 |
|---|---|
| 员工 token 过期、停用或被替换 | 每次请求重新检查；原 Context 无法同步、激活或续期。新 token 无法复用旧 Context 的凭证绑定 |
| 同人两个登记客户端 | 队列、游标和 claim 分别隔离；自报名称或复制 ID 不提供资格 |
| 复制 Alice Context 或加密包给 Bob | 当前认证主体不匹配，状态访问/文件激活拒绝；Bob 无法打开 Alice profile |
| Context 过期/关闭/显式替换 | 终态不能续活，旧 Context 不能准备任务；新 Context 初始激活为空 |
| 新 Context 配合仍有效本地文件 | 必须再次提交文件并通过当前服务端验证，之后才能多资源激活 |
| 单个文件缺失 | 关闭对应本地激活，经当前客户端领取新 ticket，同一有效包重新保存，不创建账号 |
| 单个文件损坏 | 不覆盖损坏文件；对应 Context 激活关闭，恢复有效文件后仍须重新验证 |
| 文件自然到期 | 当前授权/版本仍有效时，显式追加后继包和新租约；原期限与终态保持 |
| 单个包撤销 | 续 Context、续包、保留文件、替换 Context 均不能恢复该包；另一个资源继续有效 |
| 已消费响应丢失 | CLAIMED 保持，不回放旧响应；同步通过同包替代 ticket 恢复 |
| 并发包续期 | 每父包唯一后继；一个账号、一个开通任务、两个包，不重复创建原生账号 |
| 关键激活审计失败 / 解密期间 Context 关闭 | 激活/收据/命令不部分提交，最终状态复查拒绝迟到激活 |

服务端保存 Context 令牌 HMAC，不保存原令牌。私有 profile 固定 origin/组织/主体/登记客户端/员工凭证摘要，员工 bearer 和交付 token 不写入 session.json。每次同步有文件数、字节数、页数、任务数及时间边界。输出、MCP、网关日志和审计按实际私有值扫描，不含原令牌和包字节。

Context 运行角色对 native_secrets 无 SELECT，对 native_accounts 和客户端登记无 INSERT，也不能改客户端状态。旧 gateway 角色没有 Context、blob 和登记权限。旧下载角色可继续领取升级前手动 ticket。实际 v6 数据升级保留已消费及待领取任务、旧包/租约和历史记录；升级不制造 Context。

## 4 当前边界

MCP 只输出安全标识和状态，私有 Context/包由独立组件处理。这个证明不包含同系统用户下任意文件读取/进程执行的隔离。Windows 7 项证明针对文件和缓存实现，没有计为某个 coding 客户端原生私有适配。

本轮实现的是后续执行使用的在线 Context/Activation 资格基础。RA-10 原生 HTTP helper 与 stdio 私有适配、RA-11 正式新资源读取及派发复查、RA-13/14 完整吊销与在途停止、RA-15 密钥轮换/备份恢复 fence、RA-18 真实客户端及人工体验继续按原计划推进。没有生产部署或生产可用性验收。

最终增量检查：382 个非忽略文件扫描，171 个实际私有值无命中；57 个新增/追加文档链接有效，新增行无尾随空白。源码清单、原 81 份验证与 12 份迁移哈希均复核。
