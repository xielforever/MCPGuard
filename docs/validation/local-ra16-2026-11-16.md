## 3. 页面与 API

控制台新增「自助访问」页（现有浏览器会话 + Origin/CSRF 校验之后），调用真实服务端 API：

| 页面/动作 | API | 说明 |
|---|---|---|
| 资源 | `GET /console/api/v2/self-service/resources` | 资源状态、套餐/绑定/授予/凭据/待批写计数 |
| 凭据 | `GET .../credentials` | 只返回状态与到期，不含包内容或秘密 |
| 吊销记录 | `GET .../revocations` | 撤销审计（级别、目标、影响计数、时间） |
| 执行撤销 | `POST .../revocations` | 四级撤销，actor 记为当前浏览器身份 |
| 写审批队列 | `GET .../write-requests` | 仅返回当前审批人可见的 DEFERRED 计划 |
| 写审批决定 | `POST .../write-requests/{id}/decisions` | 禁止自批；重复决定返回 409 |

## 4. 用例断言

- `TestControlledWriteConsoleApprovals`（写场景，httptest 驱动真实 HTTP）：
  - 审批人看到队列（200，含 requestId）；
  - **申请人自批 → 403**；
  - 审批人批准 → 200/APPROVED；
  - 重复决定 → 409 `STATE_CONFLICT`（版本冲突文案可核对）。
- `TestRevocationConsolePageAndRevoke`（吊销场景）：
  - 非审批人访问资源页 → 403；
  - 审批人资源页 → 200 且响应不含 password/secret；
  - 控制台执行凭据撤销 → 200 且记录出现在吊销页；
  - 所有响应经浏览器会话/CSRF 层之后进入（沿用现有 console 中间件）。
- 标准场景 299 条旧回归通过；`console.js` 通过 `node --check`。

## 5. 边界

- 派发仍需申请人在 MCP 入口显式 resume；控制台只记录批准/拒绝决定。
- 控制台撤销要求部署方配置 `MCPGUARD_CONSOLE_REVOCATION_DSN` 与 `MCPGUARD_PROVIDER_CONFIG`；未配置时撤销 API 返回 503，不降级为假成功。
- 真实客户端、浏览器人工体验与生产部署不在本阶段。
